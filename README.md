# AppleiPhoneChoose

A polished iPhone configuration experience built with SwiftUI, inspired by Apple’s product selection flow. This project focuses on clean UI composition, reusable components, and realistic product-page interactions in a portfolio-friendly format.

## Overview

AppleiPhoneChoose is a SwiftUI app that recreates the iPhone buying experience— allowing users to select a color finish and storage capacity. The project emphasizes design fidelity, layout precision, and modular UI building patterns that are common in real-world iOS product work.

## Highlights

- Recreates an Apple-style product configuration screen
- Built with native SwiftUI views and reusable custom components
- Focused on polished spacing, color, and card-based layout design
- Demonstrates UI prototyping and visual consistency for product showcases

## Tech Stack

- Swift
- SwiftUI
- Xcode
- iOS App Development

## Features

- Finish selection cards with custom color swatches
- Capacity selection options with pricing information
- Clean, modern Apple-inspired visual language
- Responsive layout designed for iPhone app experiences

## Why this project?

This project is a strong example of front-end product design work in iOS. It combines visual design thinking with SwiftUI implementation, making it a useful portfolio piece for showcasing UI craftsmanship and app development skills.

## Run Locally

1. Open the project in Xcode.
2. Select the simulator or connected device.
3. Build and run the app.
